Help

This popup saves the page you are looking at as a ZIP that opens offline. It reads the page, steps through each carousel, reuses the files the page already loaded and downloads the rest; then the ZIP goes to your Downloads folder.

  • You can close this popup (or click on the page): the capture carries on. Click the extension's icon again to see how it is going. The icon's badge shows … while it runs, ✓ when it is done and ! if it failed.
  • Cancel stops the capture: carousels go back to their first item and nothing is saved.
  • OK becomes available when the capture ends; it clears the result, so the next click on the icon captures the page again.
  • Download again saves the same ZIP once more.
  • One capture runs at a time. While the capture runs, the browser shows an "Extension started debugging this browser" bar on the page; it is used to read the files the page already loaded and goes away at the end.
  • Unzip the file and open index.html. Anything that could not be saved is listed below the results and is left out of the snapshot, which never goes online.
